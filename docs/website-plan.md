# PENTANEX Official Website Plan

## 1. Project Goal

Build a professional public website for PENTANEX, an Australian data centre development company. The first flagship project is the 980 Hume Freeway 560MW campus.

The website should support three business goals:

1. Establish trust with investors, enterprise customers, government, energy partners, and local stakeholders.
2. Present the 980 Hume Freeway project as a credible AI-ready hyperscale data centre campus.
3. Create a consistent public contact system with a dedicated domain, support email, enquiries email, and phone number.

## 2. Positioning

PENTANEX should not look like a generic construction company or a generic IT service provider. The brand should sit between infrastructure finance, hyperscale engineering, and sovereign AI infrastructure.

Recommended positioning:

> PENTANEX develops AI-ready digital infrastructure for Australia's next era of compute.

Core brand ideas:

- Australian digital infrastructure
- Hyperscale-ready land and power strategy
- AI and cloud workload readiness
- Grid-aware, sustainability-conscious development
- Secure, resilient, enterprise-grade facilities
- Long-term partnership with community, utilities, and customers

## 3. Reference Direction

Observed patterns from the reference category:

- NEXTDC uses concrete facility metrics, certifications, location, uptime, technical space, capacity, and tour/contact calls to action.
- AirTrunk leans into hyperscale campuses, sustainability, speed of delivery, and regional digital growth.
- AWS and Microsoft infrastructure pages focus on trust, security, global operating discipline, AI infrastructure, and compliance.

PENTANEX should borrow the professionalism and clarity, but differentiate through a more cinematic, infrastructure-led visual identity:

- Less corporate brochure, more high-precision engineering.
- Less generic blue cloud language, more physical site, power, fibre, cooling, and compute density.
- Use dark technical surfaces, precise grid systems, topographic/site-plan inspired graphics, and restrained high-energy accents.

## 4. Visual System

Recommended style:

- Base: near-black, graphite, off-white, steel grey.
- Accent: electric cyan or blue-green, with a restrained amber or lime accent for energy/power indicators.
- Layout: editorial infrastructure feel, dense but calm.
- Typography: modern sans-serif, strong numeric treatments, clear hierarchy.
- Motion: subtle grid scanning, line tracing, data flow, facility module reveals.
- Imagery: real or realistic data centre exterior/interior, transmission infrastructure, aerial land/campus view, cooling/mechanical plant, secure operations.

Avoid:

- Overused purple-blue gradient SaaS style.
- Cartoon cloud illustrations.
- Empty abstract tech backgrounds with no infrastructure signal.
- Claims like Tier IV, 100% uptime, renewable energy, or specific certifications unless verified.

## 8. Technology Plan

Recommended stack:

- Framework: Next.js
- Styling: Tailwind CSS
- UI: custom components with lucide icons
- Hosting: Vercel for initial launch, with Cloudflare in front if needed
- Analytics: Plausible, Fathom, or GA4
- Forms: server-side contact form with spam protection
- Email delivery: Resend, SendGrid, or Microsoft/Google SMTP integration

Reasons:

- Fast enough for a premium marketing site.
- Easy to deploy and maintain.
- Strong SEO and performance.
- Supports future pages, news, investor content, and brochure downloads.

## 10. Development Phases

### Phase 0: Foundation

- Confirm brand name, domain direction, public claims, and contact requirements.
- Create content architecture and first copy draft.
- Create visual direction and design tokens.

### Phase 1: Prototype

- Build one-page high-fidelity homepage.
- Add responsive navigation, hero, project section, capabilities, sustainability, and contact.
- Use placeholder but polished imagery/visuals where real assets are missing.

### Phase 2: Full Website

- Expand to multi-page website.
- Add SEO metadata, structured content, contact forms, privacy page, and accessibility checks.
- Add performance optimization and production build.

### Phase 3: Public Launch

- Register domain.
- Configure DNS.
- Set up email accounts and aliases.
- Set up phone number and forwarding.
- Deploy website.
- Configure analytics, security headers, and contact form delivery.

### Phase 4: Operations

- Add news and project updates.
- Add downloadable project profile.
- Track enquiries and improve conversion.
- Maintain content for planning, community, and customer milestones.
